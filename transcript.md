# The Peacock: site copy transcript

HOW TO EDIT THIS FILE
- Only change the text UNDER each [ID] line. Leave the [ID] lines alone so I can find each piece of text again.
- Each new line in a block is a line break on the page. Add or remove lines if you want.
- Words in {curly braces} are filled in automatically from one master file (address, phone, hours). You can move them around or delete them, but don't type an address, phone number or opening hours by hand. Those have to stay the same everywhere for Google.
- To delete a block completely, write DELETE under its ID.
- Arrows (↗ ↘ ↑) and the ✳ are decorative. Keep them or drop them.
- Want a note to me instead of an edit? Start the line with >> (for example ">> make this shorter").
- Not included: the dish names and descriptions on the menu page (they come from the café's own menu boards in src/lib/menu.ts), and the owners' login area. Tell me if you want those added too.
